# NumPy Learning

A collection of NumPy examples and exercises documenting my journey in Python numerical computing.

## Topics Covered

### 1. Array Basics and Initialization
- Creating NumPy arrays
- Array dimensions, shape, data types, and memory size
- Initializing arrays with zeros, ones, and specific values
- Generating random arrays
- Creating identity matrices
- Repeating and copying arrays

### 2. Indexing and Slicing
- Accessing and modifying array elements
- Indexing and slicing 1D, 2D, and 3D arrays
- Working with array sections and nested matrices

### 3. Mathematical Operations
- Adding, subtracting, multiplying, and dividing array elements
- Squaring array elements
- Performing element-wise operations on arrays
- Calculating sine and cosine values
- Modifying individual array elements

### 4. Linear Algebra
- Matrix multiplication using `np.matmul()`
- Finding the inverse of a matrix using `np.linalg.inv()`
- Calculating the determinant using `np.linalg.det()`
- Adding matrices using `np.add()`

### 5. Statistics
- Finding minimum and maximum values
- Calculating minimum and maximum values by row and column

### 6. Reshaping and Combining Arrays
- Reshaping arrays with `reshape()`
- Vertically stacking arrays with `np.vstack()`
- Horizontally stacking arrays with `np.hstack()`

### 7. File Handling
- Loading numerical data from text files using `np.genfromtxt()`

### 8. Boolean Masking and Advanced Indexing
- Filtering array elements using conditions
- Checking conditions across columns with `np.any()`
- Combining conditions with Boolean operators

## How to Use

1. Clone or download this repository.
2. Open the notebooks in Jupyter Notebook or VS Code.
3. Run the cells to explore the examples and practice NumPy concepts.
