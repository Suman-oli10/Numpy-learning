# NumPy Learning

A collection of NumPy examples and exercises documenting my journey in Python numerical computing.

## Topics Covered

- NumPy array creation and basics
- Array dimensions, shape, data types, and memory size
- Accessing and modifying array elements
- Indexing and slicing 1D, 2D, and 3D arrays
- Initializing arrays with zeros, ones, and specific values
- Generating random arrays
- Creating identity matrices
- Repeating and copying arrays
- Working with array sections and nested matrices

## Repository Structure

## Requirements

- Python
- NumPy
- Jupyter Notebook

Install NumPy using:

```bash
pip install numpy
```

## How to Use

1. Clone or download this repository.
2. Open the notebooks using Jupyter Notebook or VS Code.
3. Run the cells to explore the examples and practice NumPy concepts.
